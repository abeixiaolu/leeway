# 01: 个人空间与可用资金账户

**What to build:** 使用者可以用昵称和私人密码进入自己的财务空间，创建可用资金账户并指定默认消费账户，随后在手机或电脑上看到正确余额。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 新使用者可用唯一昵称和私人密码创建财务空间；再次访问时需密码验证，只有昵称不能读取数据。
- [ ] 不同使用者只能查看和操作自己的账户与记录；密码不会以明文保存。
- [ ] 使用者可创建多个可用资金账户，创建时填写人民币初始金额，之后没有直接编辑余额的入口。
- [ ] 使用者可从可用资金账户中指定或更换默认消费账户，并看到当前账户余额及可用资金总额。
- [ ] 手机和桌面宽度都能完成上述流程；创建时说明首版没有密码找回。
