# 07: 借贷与偿还本金

**What to build:** 使用者可以查看借贷未偿本金，在每月固定还款扣除现金后记录其中偿还的本金，使负债准确减少。

**Blocked by:** 06 固定支出自动扣款。

**Status:** ready-for-agent

- [ ] 可创建借贷账户并填写初始未偿本金，创建后不能直接编辑余额。
- [ ] 固定还款扣除默认消费账户且只计入一次实际支出；可为该月还款记录偿还的本金。
- [ ] 偿还本金只减少借贷余额，不再次减少可用资金，也不再次计入支出。
- [ ] 本金记录不可使借贷余额低于零；可更正错误本金记录并重算借贷余额。
- [ ] 可查看各笔借贷与未偿本金总额。
