# 03: 投资账户与价值变动

**What to build:** 使用者可以录入投资资产，并用单独的价值变动记录反映上涨或下跌，而不把涨跌误算为收入或支出。

**Blocked by:** 01 个人空间与可用资金账户。

**Status:** ready-for-agent

- [ ] 可创建投资账户并填写初始人民币价值，创建后不能直接修改余额。
- [ ] 可记录正数或负数的投资价值变动，投资账户余额据此更新。
- [ ] 投资价值变动不改变可用资金、当月实际收入或当月实际支出。
- [ ] 可查看投资账户列表、各账户当前价值和投资资产总额。
- [ ] 可更正或删除错误的价值变动记录，当前价值随之重算。
