# 08: 财务概览与安全月数

**What to build:** 使用者打开首页即可看清资产、负债、当月收支、日常额度和资金还能覆盖几个月的计划支出。

**Blocked by:** 02 快速记账与月度额度；03 投资账户与价值变动；04 手动收入；06 固定支出自动扣款；07 借贷与偿还本金。

**Status:** ready-for-agent

- [ ] 首页以人民币展示可用资金、投资资产、借贷余额及净资产，并以中国时间确定当月。
- [ ] 首页展示当月实际工资与理财收入、日常支出、固定支出及日常额度剩余；转账、投资涨跌和偿还本金不重复计入收支。
- [ ] 实际可支撑月数按可用资金总额除以当月计划支出计算；计划支出为固定支出与该月日常消费额度之和，不抵扣收入。
- [ ] 默认安全月数目标为 6 个月，使用者可修改；首页能清楚比较实际月数与目标。
- [ ] 计划支出为零时显示“暂无月度支出计划”；可用资金为零或负数时显示 0 个月并提示资金缺口。
- [ ] 手机与桌面布局均能清晰查看主要数字与状态。
