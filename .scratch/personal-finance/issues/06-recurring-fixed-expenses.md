# 06: 固定支出自动扣款

**What to build:** 使用者设置房租、还贷等固定支出及每月扣款日，系统按期自动从默认消费账户扣款，并在月度支出中展示。

**Blocked by:** 01 个人空间与可用资金账户；02 快速记账与月度额度。

**Status:** ready-for-agent

- [ ] 可创建、修改、停用固定支出，设置名称、金额和每月扣款日；变更只影响未来，历史扣款保留。
- [ ] 每项固定支出到期后自动生成一笔支出；配置在 29、30 或 31 日而当月没有该日时，在当月最后一天扣款。
- [ ] 同一固定支出同一个月只扣一次，即使自动任务重试或应用重启。
- [ ] 扣款减少默认消费账户余额并计入当月实际支出，但不占用日常消费额度。
- [ ] 余额不足时仍完成扣款，允许负余额并清楚显示资金缺口。
