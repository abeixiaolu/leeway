# Domain docs

This repo uses a single-context layout: `CONTEXT.md` at the root and ADRs under `docs/adr/`. These files are created when domain terms or decisions need recording.

Before exploring an area, read the relevant existing `CONTEXT.md` and ADRs. If they do not exist yet, proceed without flagging their absence.

Use terms defined in `CONTEXT.md` when naming concepts in issues, proposals, hypotheses, and tests. If a needed term is missing, reconsider the wording or note the gap for domain modeling.

If proposed work conflicts with an ADR, identify the conflict explicitly rather than silently overriding the decision.
